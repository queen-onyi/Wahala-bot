# Wahala Bot 🇳🇬

A terminal chatbot that speaks Naija Pidgin + English like a Nigerian.

## What it does

- **Pidgin + English**: replies with real Naija vibes (abeg, wahala, how far, I dey, no wahala).
- **Mood Reader**: reads your mood from how you type. Short, small-letter messages get a soft reply. Messages with !!!, emojis, or CAPS get a hyped reply.
- **Memory**: remembers things you tell it and saves them in `memory.json`. Next time you open the bot, it greets you with what it remembers.
- **Safety check**: if you type words about ending your life, the bot stops joking and responds with care.

## How to run

You need Python 3 installed.

```
python app.py
```

## Things to type

- `my name is...` saves your name
- `remember that...` saves a fact
- `what do you remember` shows everything it knows
- `bye` closes the bot
